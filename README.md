# Fuel-Mix Carbon-Intensity Forecasting

Minimal runnable package and results for the paper's seven-region experiments:
ISO-NE, NYISO, PJM, ERCOT, CAISO, MISO, and IESO, over January 2024 to December
2025. Everything runs from the included CSVs; no API access or key is needed.
Run commands from this directory.

The two-year rerun follows [`PROTOCOL_2024_2025.md`](PROTOCOL_2024_2025.md),
which was committed before the 2025 data were fetched; its addendum records
the data-handling decisions made after the data check and before any fit.

## Setup

```bash
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r requirements.txt
```

## Reproduce the paper

One driver runs every experiment single-threaded, so retraining reproduces
the tables exactly. Keep the model and prediction caches outside the package:

```bash
CACHE=/tmp/carbon_two_year bash scripts/paper/run_two_year_rerun.sh
python3 scripts/paper/polish_paper_figures.py --preview-dir /tmp/carbon_figure_previews
python3 scripts/paper/make_timeseries_figures.py --preview-dir /tmp/carbon_figure_previews
```

The figure scripts write PDFs to `paper_figures/` (not tracked; change it
with `--output-dir`) and PNG previews to `--preview-dir`.

The driver's phases can also be run separately, in this order:

- `fixed`: three-seed Fuel-mix ensembles (day-ahead-like and short-horizon),
  Direct MLP and persistence tables, and the ERCOT wind/solar variants.
- `rolling`: five 2025 windows for all regions and variants, plus the 2024
  windows (Jun/Aug/Oct) on the two-year table as the short-history contrast.
- `decision`: MSE/SPO+ 2x2 in all seven regions and the ERCOT ten-seed audit
  (lambda fixed at 10).
- `intervals`: independent-calibration and OOF interval audit, in the
  day-ahead-like setting reported in the paper and in the one-hour-lag setting
  declared in the protocol (see its deviation note).
- `contribution`: fuel-contribution check, the target-definition check, and
  the 2025 region overview.
- `sensitivity`: one-at-a-time loss-weight sensitivity on the fixed split.
- `tables`: `collect_paper_tables.py` concatenates per-region outputs and
  refreshes `results/summary/`.

Run one region:

```bash
python3 src/run_fuelmix.py \
  --config configs/dayahead/ercot_fuelmix_dayahead.json \
  --stage train --seed 42 --device cpu
```

## Data

Configs read `[2024, 2025]` file lists from `data/<REGION>/_raw/` and
`data/<REGION>/_raw_2025/`. The files are hourly
extracts of public ISO data obtained through gridstatus.io: the `*_fuel_mix`
datasets and the load forecasts `isone_load_forecast_hourly`,
`nyiso_load_forecast_hourly`, `pjm_load_forecast_hourly_historical`,
`ercot_load_forecast_dam`, `caiso_load_forecast_day_ahead` (CA ISO-TAC),
`miso_load_forecast_mid_term`, and `ieso_load_forecast_hourly`, each taking the
latest publication no later than the target hour.

- ERCOT wind/solar features come from `ercot_wind_actual_and_forecast_hourly`
  and `ercot_solar_actual_and_forecast_hourly` (forecast columns only), in two
  vintages: the latest publication no later than the target hour (median lead
  five minutes, an upper bound) and the latest at least 24 hours ahead. They
  are used only by `configs/dayahead/ercot_rnw0_*` and `ercot_rnw24_*`.
- IESO: gaps in the 2024 load feed were filled from the pre-renewal zonal
  feed. The 2025 feed has a 109-hour gap after the May 2025 market renewal
  that no earlier-published forecast can fill; those hours and the 24 hours
  whose lags fall in the gap are dropped.
- ERCOT storage is a signed net series from the 2025-12-05 RTC+B launch;
  charging is clipped to zero, as for CAISO, MISO, and IESO.

## Retained results

- `results/summary/`: compact paper tables, including the seven-region
  MSE/SPO+ 2x2 (`spoplus_2x2_seven_regions_*.csv`) and the loss-weight
  sensitivity.
- `results/aligned_protocol/`, `results/experiments/method_metrics/`:
  fixed-split comparison and metrics, including the ERCOT wind/solar variants.
- `results/rolling_rmse_aligned/`: 2025 windows (pooled and per-window RMSE,
  scheduling, paired Wilcoxon tests, fitting audit).
- `results/rolling_2024_windows/`: 2024 windows on the two-year table.
- `results/rolling_ercot_ws/`: ERCOT baseline and wind/solar variants on the
  2025 windows.
- `results/experiments/spoplus_2x2_ercot/`, `results/robustness_seeds/`:
  decision-focused training and the ten-seed audit with block intervals.
- `results/robustness_intervals_dayahead/`: interval metrics, temporal
  audits, and curves in the day-ahead-like setting (the paper's table);
  `results/robustness_intervals/` holds the declared one-hour-lag run.
- `results/summary/region_overview_2025.csv`: the paper's region table.
- `results/attribution/`: fuel-contribution check and the ERCOT case window.

Model checkpoints, hourly predictions, plots, and logs are regenerated by the
scripts.

## Scope

The benchmark is day-ahead-like: historical realized features are lagged 24
hours, but load-forecast vintages use the latest publication no later than the
target hour. It is not a fixed H-24 issuance benchmark. The target is a
load-forecast-normalized emissions proxy, fixed-factor emissions divided by the
latest published load forecast, not a production-based or flow-traced
consumption-based intensity (`results/summary/ci_definition_check.csv`
compares it with the generation-normalized intensity). Scheduling evaluation
is open-loop and measures selection of low-proxy hours, not avoided emissions;
the 1/6 cap allocates one sixth of daily energy to each of six hours.
The paper's interval results use the day-ahead-like setting.
